In essence, it's a valuable resource for anyone seeking to connect with or consider me for opportunities.

## Tech Stack

**Client:** Nuxt3, TailwindCSS

## Construire l'image Docker

Utilise le `Dockerfile` pour exécuter l'application.

1. Clone the project

    ```bash
    git clone https://github.com/leoteissier/portfoliov2.git
    ```

2. Go to the project directory

    ```bash
    cd portfolio
    ```

3. Build the Docker container for development

    ```bash
    sudo docker build -f Dockerfile -t portfolio-app .
    ```

4. Open your browser and go to [http://localhost:3000](http://localhost:3000) to view the application.
